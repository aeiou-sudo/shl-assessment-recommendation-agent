# SHL Assessment Recommendation Agent

An AI-powered conversational recommendation system that helps recruiters identify relevant SHL assessments using Retrieval-Augmented Generation (RAG), hybrid retrieval, and conversational AI.

## Features

- Conversational recruiter interaction
- Hybrid retrieval (BM25 + embeddings)
- SHL assessment recommendation engine
- FastAPI backend
- Evaluation framework
- Dockerized deployment

## Tech Stack

- FastAPI
- FAISS
- Sentence Transformers
- BM25
- Cross Encoder Re-ranking
- Docker
